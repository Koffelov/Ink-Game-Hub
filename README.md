# Ink Game Hub

Отдельный клиентский скрипт **Ishak Hub** с функцией **Help Players** для Red Light Green Light в Ink Game. Другие функции Moon Hub в `main.lua` не включены.

## Использование

Запуск через `loadstring` в совместимой клиентской среде:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Koffelov/Ink-Game-Hub/main/main.lua"))()
```

1. В текущем раунде Red Light Green Light встань у куклы в точке, куда нужно доставлять игроков.
2. Нажми **«Сохранить точку у куклы»**.
3. Включи **Help Players**. Скрипт ищет раненого игрока, перемещается к нему, пытается активировать взаимодействие без удержания и после подтверждения поднятия возвращается к сохранённой точке.
4. Отпусти доставленного игрока вручную, чтобы помочь следующему.

Клавиша **Z** скрывает и показывает меню. При смене раунда, смерти или возрождении функция выключается; точку для нового раунда нужно сохранить заново.

## Ограничения и проверка

- Ожидается `Workspace.Values.CurrentGame.Value == "RedLightGreenLight"`.
- Ранение определяется по объектам `InjuredWalking` или `Crawling` в персонаже либо соответствующей модели в `Workspace.Live` / `Workspace.Live.GreenPlayers`.
- Взаимодействие ищется среди включённых `ProximityPrompt` по словам `carry`, `pickup`, `help`, `revive` или `rescue` в имени или `ActionText`. Поднятие подтверждается физическим соединением частей персонажей.
- Если игра использует другую структуру объектов или взаимодействий, потребуется адаптация. Изменение `HoldDuration` на клиенте не гарантирует мгновенного взаимодействия на сервере.
- Отдельный скрипт прошёл синтаксическую проверку и компиляцию Luau; прошли **36 тестов с имитациями объектов**. В самой игре скрипт не проверялся. Работа телепорта и отсутствие детекта не гарантированы.
- `main.lua` не загружает сторонние скрипты или UI-библиотеки.
