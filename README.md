# Ink Game Hub — Ishak Hub

Полный хаб на основе HSX для Ink Game с дополнительной функцией **Help Players** в разделе **Games → Red Light Green Light**. Сохранены исходные вкладки Information, Games, Powers & Surgery, Combat, Players, Guards, Main, MainExtras, Extras и Settings, а также их функции. Интерфейс переименован в **Ishak Hub**.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Koffelov/Ink-Game-Hub/ca8d2fcc22b97f27766580bb1d09e72bfa1d5fa8/main.lua"))()
```

Загрузчик закреплён на проверенном коммите полной версии.

В репозитории находятся main.lua и необходимые библиотеки интерфейса: library.lua, ThemeManager.lua, SaveManager.lua. Основной скрипт загружает эти библиотеки из этого же репозитория. Клавиша **Z** управляет меню.

## Help Players

1. В раунде Red Light Green Light открой **Games → Red Light Green Light**.
2. Выбери **End Corner**: Left Corner или Right Corner. Это штатные точки функции Teleport to End в исходном HSX.
3. Включи **Help Players**. Скрипт обрабатывает раненых по одному: телепортируется к игроку, временно убирает удержание у подходящего взаимодействия, пытается поднять игрока и ждёт подтверждения переноса.
4. После подтверждения возвращается к выбранному End Corner и проверяет прибытие обоих персонажей. Отпусти доставленного игрока вручную, чтобы помочь следующему.

Переключатель по умолчанию выключен. Выключение, смерть, возрождение, смена игры или выгрузка хаба отменяют работу; длительность взаимодействия и зажатый ввод восстанавливаются. Глобальный Instant Interact переключать не требуется.

Ранение определяется по объектам InjuredWalking / Crawling. Подходящий включённый ProximityPrompt ищется по словам carry, pickup, help, revive или rescue; поднятие подтверждается физическим соединением частей персонажей. Если игра использует другую реализацию переноса, понадобится адаптация по фактическим объектам игры. Отсутствие ранения само по себе не считается подтверждением поднятия.

## Проверка и сохранение функций

- Основной скрипт и все три библиотеки прошли компиляцию официальным Luau 0.743.
- Сохранены все 10 исходных вкладок и все 340 различных определений функций MainModule; Help Players встроен в существующую RLGL-секцию.
- Прошли 41 тест контроллера и 11 тестов интеграции с имитациями объектов, включая выбор End Corner, штатный телепорт, отмену, ошибки взаимодействия и отказ/откат телепорта. В самой игре хаб не запускался.
- Сохраняются ограничения и возможные ошибки отдельных функций исходного HSX. Компиляция не подтверждает их работу в текущей версии игры или конкретном исполнителе.
- Телепорт использует существующий MainModule.safe_teleport. Отсутствие детекта не гарантируется.

Дополнительно исправлены отсутствующие звуковые псевдонимы. Убран автоматический вызов неопределённого глобального webhook и автоматическое копирование Discord-рекламы при запуске; явная кнопка Discord в информационной вкладке сохранена. Пути сохранённых настроек и ресурсов HSX оставлены совместимыми с исходником.

В исходном хабе остаётся отдельная функция Fake LG PowerHold, которая по включению загружает внешний Luarmor-скрипт; библиотека интерфейса также загружает внешний пакет иконок. Эти зависимости не относятся к Help Players и не исполнялись при проверке.
